◠◡ Wi-Fi Survey docs
v0.1 · self-hosted · LAN only

See exactly where your Wi‑Fi is good.

Wi-Fi Survey is built to turn a 3D scan of your home into an interactive coverage map: you place your access points, walk the rooms with a laptop or phone, and the server turns those readings into heatmaps, a wall-aware propagation model and a live position estimate — all on your own hardware, with no cloud account and no data leaving the LAN. v0.1 ships the scaffold (install, model import, pairing, reading ingest); the survey and modelling chapters are marked planned.

What you get

v0.1 is a scaffold — read this first

Working today: the installer, the first-run wizard, 3D model import through modelkit, node pairing, reading ingest and the 3D viewer. Planned, not built: walk-and-tap survey runs, heatmaps, propagation calibration, live position, UniFi controller polling and the tuning engine. Pages about those features say so at the top; nothing here promises them in v0.1.

01 · map Your real floor plan

Upload a GLB, glTF, OBJ or Polycam export. The importer detects floors and extracts wall lines automatically; the in-browser wall confirm editor is planned.

02 · measure Walk-and-tap surveying

A laptop agent, an Android node or an ESP32 can feed the same reading schema today. The tap-to-place walking screen and 15-second samples are planned.

03 · model Maps you can trust

Planned: IDW and kriging maps of what you measured, plus a log-distance model with wall losses, calibrated against your data and scored on held-out points.

04 · tune Suggestions, not surprises

Planned: rule-based channel and power recommendations with dry-run by default, one change at a time and rollback if anything gets worse. v0.1 writes nothing to an AP.

From zero to a first run

The installer is one command on a Linux box on the same network as your access points. It needs no cloud account, no DNS and no open ports beyond the one you choose.

git clone https://github.com/ImVexi/wifi-survey.git
cd wifi-survey
less installer/install.sh     # read it before you run it
sudo installer/install.sh     # installs to /opt/wifi-survey, defaults to port 8800

When it finishes, open http://survey.local:8800, paste the viewer token it printed, and follow the quickstart. In v0.1 that gets you an imported floor plan and a paired node posting readings; the heatmap arrives with the survey engine.

Not supported yet

Windows and macOS server installs, cloud sync, multi-site management and automatic AP discovery without credentials. The scanner agents run on Linux, Android/Termux and ESP32 only — see Scanner nodes for the exact capability of each.

What this tool is honest about

Wi-Fi is physics plus a lot of firmware quirks. A survey point is a measurement at one spot and one moment; a heatmap is an interpolation between those spots, not a photograph of your radio field. The model is calibrated to your building and reports its own held-out error — typically 4–7 dB in a house with drywall and a few brick walls. Position estimates land within about 2–4 m when you have taken 10–15 points per floor, and the UI says "cannot estimate" instead of guessing when the fingerprint is too far from anything it has seen. All of that is explained in Concepts.
