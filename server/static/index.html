Choose an admin password

At least 8 characters. It protects the dashboard and pairing codes; there is no recovery e-mail.

Upload your 3D scan

A GLB, glTF or OBJ export from a phone scan or a CAD tool. The pipeline runs locally and is deterministic: floors, walls, plans and metadata are derived from the mesh, never from a model in the cloud.

Name your floors

Floor 0 is the lowest level found in the scan. Names appear in the viewer and in node position pickers.

Add access points (optional)

Add them by hand now, or import read-only details from a local UniFi controller. You can change this later.

One-time pairing code

------

On the scanning device run:

wifi-survey-agent --server http://<this-host>:8800 --pair-code <code> --node-id laptop-hall

The code is valid for ten minutes and works once. The node receives its own token.
